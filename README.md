## English

A personal study repository with notes and examples for three courses: Big Data, Human–Computer Interaction (HCI), and Network Programming. Each chapter can be read as a web page.

**[Open the study site →](https://bass131.github.io/KNUT_2ND/)**

Use the **한국어 / English** buttons on each page to switch the language of the content and navigation. Your choice is kept when you move to another page or reload. Code, commands, original filenames, and screenshots of actual runs are left unchanged. Translations are built into the pages, so no external translation service is used.

| Big Data | Human–Computer Interaction (HCI) | Network Programming |
| :---: | :---: | :---: |
| [![Illustration of data processing and analysis](site/assets/readme-bigdata.png)](https://bass131.github.io/KNUT_2ND/BigData/) | [![Illustration of people interacting with an interface](site/assets/readme-hci.png)](https://bass131.github.io/KNUT_2ND/HumanComputerInteraction_HCI/) | [![Illustration of computers connected to a server](site/assets/readme-network.png)](https://bass131.github.io/KNUT_2ND/Network_Programing/Lecture_HTML/) |
| Chapters 1–4: concepts and DataFrames | Chapters 1–5: full lectures and emphasis summaries | Chapter 1, 2-1, 2-2: socket lectures and C examples |

The [Big Data lab instructions](https://bass131.github.io/KNUT_2ND/BigData/practice/) cover the setup, full code, input data, and expected results.

- [Execution observation lab ZIP](https://bass131.github.io/KNUT_2ND/BigData/downloads/spark-execution-lab.zip): observe Spark execution on a Master, Worker 1, Worker 2, and Client setup.
- [Performance comparison lab ZIP](https://bass131.github.io/KNUT_2ND/BigData/downloads/spark-performance-lab.zip): compare run times while changing the number of Workers and the core limit.

If you have downloaded the repository, open `site/index.html` in Chrome or Edge. The study pages need no server or build step. The Docker and Spark labs require the environment described in each chapter.

The published files are the study pages with their required images, styles, and scripts, the network C examples, selected Big Data lab files, and the two lab ZIPs. Original lecture PDFs and PPTX files, extracted slide images, working documents, QA records, test code, and other ZIP files are not included.
